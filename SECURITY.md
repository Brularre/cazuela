# Security Policy

## Supported versions

Only the current `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use GitHub's private
[Security Advisory](https://github.com/your-username/cazuela/security/advisories/new)
feature to report vulnerabilities confidentially. You can expect an
acknowledgement within 72 hours and a fix timeline shortly after. We will
credit you in the changelog unless you prefer otherwise.

## Scope

**In scope:** authentication bypasses, session fixation, SQL injection,
cross-user data exposure, insecure direct object references.

**Out of scope:** rate limiting complaints, issues in third-party services
(Meta, Supabase, Railway), social engineering.
